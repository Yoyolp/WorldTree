# 第一章 · 录取通知书 {id=ch01}

七月。雨停了，屋檐还在滴水。

你把第三封信摊在桌上。前两封被大人拿走了，说「寄错了」。这一封你藏在了床垫下面。

羊皮纸，绿色墨水，收信人写的是你的全名，还有一个你从没告诉过任何人的细节：你的房间朝北。

信里只有两段话：霍格沃茨魔法学校录取你为一年级新生；九月一日，国王十字车站，九又四分之三站台。

窗外传来一声很轻的响动。一只灰白色的猫头鹰正站在窗台上，歪着头看你，像在等你决定。

::: director
用调查员的克制笔法写这一幕：不惊叹，只观察。让孩子的好奇压过恐惧。
:::

::: event 猫头鹰的信 once chance=100%
猫头鹰把爪子抬起来。它的腿上绑着一根细麻绳，绳子上系着一枚铜片——上面刻着一个数字：7。
:::

# 第二章 · 夜里的访客 {id=ch02}

7 月 31 日，夜里十一点四十。

门被敲响的时候，整栋房子的灯都灭了。不是有人关的——是灯自己灭的。

敲门声很重，一下一下，像有人用整个手掌拍门。

门外站着一个几乎顶着门框的巨人，胡子结着霜，手里提着一个被压扁的盒子。

「你等了很久了吧。」他说，声音大得像打雷，但语气很轻，「我叫鲁伯·海格。霍格沃茨的钥匙保管员。」

:::

::: director
海格是这个世界第一个对玩家好的人。让玩家和他一起松一口气。
:::

# 第五章补 · 火车上的偶遇 {id=ch05b}

包厢门被推开。一个红头发、满脸雀斑的男孩探进头来：「这儿有人吗？」

他叫罗恩·韦斯莱。他有一整包比比多味豆，和一张邓布利多的巧克力蛙卡片。

后来，一个头发蓬乱的女孩推门进来：「你们有人见过一只蟾蜍吗？纳威的。」

她叫赫敏·格兰杰。她一口气说出四个学院的名字，然后纠正了罗恩的咒语发音。

「你就是那个……？」铂金头发的男孩扫了你一眼，「我听说你也在这一届。马尔福。德拉科·马尔福。」

# 第九章补 · 观察斯内普 {id=ch09b}

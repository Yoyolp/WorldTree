# 第一章 · 多比的警告 {id=ch01}

暑假的最后一周。女贞路四号，哈利的卧室窗户上装着铁栏杆。

一个家养小精灵坐在他的床上，耳朵像蝙蝠翅膀，眼睛有网球那么大。

「哈利·波特不能回霍格沃茨。」它说，「今年会有可怕的事情发生。」

::: director
这是续作的开场。如果玩家带着上一部的能力与关系进来，让多比也「知道」这些事——比如它听说过你干过什么。
:::

::: event 多比的警告 once chance=100%
小精灵用头撞墙，撞得砰砰响。「多比必须阻止哈利·波特回去！」
:::

- [问它到底有什么危险] -> ch02
- [直接拒绝，我要回学校] -> ch02

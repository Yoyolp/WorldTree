# 03 · 世界书编写

世界书（World Book / World Info）是**按关键词动态注入的背景设定**。
模型不会永远记得所有设定——只在提到相关内容时，把对应条目塞进提示词。

---

## 文件位置

```
content/worldbooks/*.json
```

支持两种格式，启动时自动识别：

| 格式 | 判断依据 |
|---|---|
| 世界树原生 | 有 `id` 字段且 `entries` 是**数组** |
| SillyTavern World Info | 其它情况（`entries` 是对象或扁平格式） |

---

## 世界书整体字段

```json
{
  "id": "hp-worldbook",
  "name": "哈利·波特世界书",
  "description": "霍格沃茨背景设定",
  "scanDepth": 6,
  "tokenBudget": 4000,
  "recursiveScanning": false,
  "entries": [ ... ]
}
```

| 字段 | 默认 | 说明 |
|---|---|---|
| `scanDepth` | 6 | 扫描最近 N 条消息拼成匹配窗口 |
| `tokenBudget` | 4000 | 注入总字符预算，超了就按优先级截断 |
| `recursiveScanning` | false | 命中的条目内容再扫一次，可能带出更多条目 |

---

## 条目字段（完整）

```json
{
  "id": "entry_hogwarts",
  "comment": "霍格沃茨总述",
  "keys": ["霍格沃茨", "Hogwarts", "学校"],
  "secondaryKeys": ["城堡", "魔法"],
  "selective": true,
  "selectiveLogic": "and",
  "constant": false,
  "caseSensitive": false,
  "useRegex": false,
  "matchWholeWords": false,
  "priority": 100,
  "insertionOrder": 0,
  "position": "before_char",
  "depth": 0,
  "probability": 100,
  "useProbability": false,
  "group": "",
  "cooldown": 0,
  "sticky": 0,
  "content": "霍格沃茨是一所魔法学校……",
  "maxChars": 0,
  "enabled": true,
  "image": "assets/wb_hogwarts.png",
  "imageCaption": "霍格沃茨城堡"
}
```

### 关键词

| 字段 | 说明 |
|---|---|
| `keys` | 主关键词。**命中任意一个**即视为候选 |
| `secondaryKeys` | 次关键词，配合 `selective` 使用 |
| `selective` | 是否启用次关键词判定 |
| `selectiveLogic` | `and`（次关键词必须命中）/ `or`（主命中即可）/ `not`（次关键词不得命中） |

一个 `keys` 元素可以写逗号分隔的多个词，如 `"霍格沃茨, Hogwarts"`，
表示「这两个词任一命中都算这条关键词命中」。

### 匹配选项

| 字段 | 说明 |
|---|---|
| `caseSensitive` | 大小写敏感 |
| `useRegex` | 把关键词当正则解析 |
| `matchWholeWords` | 整词匹配（避免 `cat` 命中 `category`） |

### 注入控制

| 字段 | 说明 |
|---|---|
| `constant` | **常驻**：无视关键词，只要启用就注入 |
| `priority` | 越大越优先（预算不够时先砍小的） |
| `insertionOrder` | 同优先级内排序 |
| `position` | `before_char` / `after_char` / `at_depth` |
| `depth` | `position=at_depth` 时的插入深度（0=紧贴最新消息） |
| `maxChars` | 单条最大注入字符数，0=不限 |
| `enabled` | 是否启用 |

### 触发概率与冷却

| 字段 | 说明 |
|---|---|
| `probability` | 0-100，配合 `useProbability` |
| `useProbability` | 是否启用概率 |
| `cooldown` | 触发后冷却多少回合 |
| `sticky` | 触发后保持多少回合有效 |
| `group` | 分组，同组内只取优先级最高的一个 |

### 配图（平台扩展）

| 字段 | 说明 |
|---|---|
| `image` | 配图路径，形如 `assets/wb_xxx.png` |
| `imageCaption` | 图注，显示在图片下方 |

**配图不注入提示词，不占 token 预算**，纯展示用。
命中该条目时会在阅读器的消息气泡里显示缩略图，点击可放大。

详见 [06-图片与附件](./06-图片与附件.md)。

## 扫描算法（`lib/lore.ts`）

每回合按下面顺序执行：

```
1. 取最近 scanDepth 条消息 + 本回合玩家输入 → 匹配窗口
2. 逐条判定：
   ├─ enabled? 否则跳过
   ├─ constant? → 直接入选
   ├─ 主关键词命中？ 否则跳过
   ├─ selective 且有次关键词？ → 按 selectiveLogic 判
   ├─ 冷却中？ 否则跳过
   └─ useProbability? → 掷概率
3. 同组（group 相同）只保留 priority 最高的
4. 按 priority 降序排序
5. 在 tokenBudget 内逐条累加，超了就停
6. 按 position 插入提示词的对应位置
```

### `at_depth` 的位置语义

对齐 SillyTavern：

- `depth = 0` → 紧贴最新一条消息（最靠后）
- `depth` 越大 → 往历史深处走

实现上是「附在倒数第 `depth+1` 条消息之后」的系统备注。

## 编写建议

### 1. 关键词要「具体而不易撞」

❌ 差：`"keys": ["魔法"]` —— 满篇都会命中，等于常驻，白烧预算

✅ 好：`"keys": ["魔法石", "Philosopher's Stone"]`

### 2. 用 `selective` 做消歧

「三头犬」在别的作品里也有。加次关键词限定到本作：

```json
{
  "keys": ["三头犬", "路威"],
  "secondaryKeys": ["霍格沃茨", "海格", "活板门"],
  "selective": true,
  "selectiveLogic": "or"
}
```

### 3. 常驻条目只留给「绝对不能忘」的

世界总纲、玩家身份这类可以 `constant: true`。
但常驻条目每回合都占预算，越多留给历史的空间越小。

### 4. 长条目拆开写

一条 2000 字的「霍格沃茨大全」不如拆成
「城堡布局」「四大学院」「课程」「教职员」四条，
这样只在相关话题出现时才注入。

### 5. 用 `group` 做互斥变体

同一件事的不同版本：

```json
{ "group": "分院结果", "priority": 100, "keys": ["分院"], "content": "你被分到格兰芬多…" }
{ "group": "分院结果", "priority": 100, "keys": ["分院"], "content": "你被分到斯莱特林…" }
```

同组只取一个 —— 但**注意**这取的是优先级最高的，不会按 flag 条件选。
要做「按状态分版」应该用**剧本事件的条件组**（见 [04-规则插件](./04-规则插件.md) 之外的剧本文档），
或者拆成两条互斥关键词的条目。

## 在网页上编辑

「世界书」→ 选择一本 → 左侧条目列表，右侧编辑区。

编辑器提供：

- 关键词输入（顿号/逗号分隔自动切分）
- **命中测试**：输入一段文字，实时高亮哪些条目会命中
- 注入预览：显示这条最终会以什么形式进提示词
- 配图上传

## 与 SillyTavern 互通

**导出**：`GET /api/worldbooks/:id/export` → ST World Info JSON

**导入**：`POST /api/worldbooks/import`

字段映射：

| 世界树 | ST |
|---|---|
| `keys` | `key`（数组） |
| `secondaryKeys` | `keysecondary` |
| `selectiveLogic` | `selectiveLogic`（0=AND 1=NOT 2=OR） |
| `insertionOrder` | `order` |
| `position` | `position`（0=before_char 1=after_char） |
| `enabled` | `!disable` |
| `image` / `imageCaption` | `extensions.worldtree.image` |

**平台扩展会被带出去**，其它工具会原样保留 `extensions`，导回来不丢。
